# iOS / macOS 快捷指令

用 Apple 的「快捷指令」在 iPhone、iPad、Apple Watch 或 Mac 上控制电视端的「题了个题」：一键临时解锁、查看剩余时间、立即锁定。

仓库不附带 `.shortcut` 文件。快捷指令需要在 Apple 设备上生成和签名，Windows 上无法可靠地产出可导入的二进制包，所以下面用可以照着点的步骤代替。

## 准备

1. 在家长面板打开 **设置 → 家庭自动化**，勾选 **控制**（需要查看状态的话再勾选 **只读**），点「生成令牌」，复制 `sotv_` 开头的令牌；
2. 给电视设置固定 IP（路由器里做 DHCP 地址保留），下面用 `192.168.1.20` 举例；
3. 确认手机和电视在同一个局域网，浏览器能打开 `http://192.168.1.20:8099/api/hello`；
4. iPhone / iPad 首次运行快捷指令时如果弹出「允许访问本地网络」，选择允许。

> 令牌只显示一次，建议存进密码管理器。只把 **集成令牌** 用在快捷指令里，不要使用家长管理密码。

## 配方一：临时解锁 30 分钟

适合「大人想看一会儿」或孩子临时需要查资料，不扣学习余额，到点自动恢复规则。

1. 打开「快捷指令」App，点右上角 **+** 新建快捷指令；
2. 搜索并添加操作 **获取 URL 的内容**（英文系统为 Get Contents of URL）；
3. 在 URL 一栏填：

   ```text
   http://192.168.1.20:8099/api/remote
   ```

4. 点操作里的 **显示更多**，把 **方法** 改成 `POST`；
5. **请求正文** 选择 `JSON`，添加两个字段：
   - `action`：文本 `unlock`
   - `minutes`：数字 `30`
6. 在 **头部** 里添加两项：
   - `Authorization`：`Bearer sotv_xxxxxxxxxxxxxxxx`（注意 `Bearer` 和令牌之间有一个空格）
   - `Content-Type`：`application/json`
7. 点右下角运行测试。返回内容里应包含 `"learning"` 和 `"override"`；
8. 给快捷指令改名为「解锁电视 30 分钟」，再添加到主屏幕、锁定屏幕小组件，或设置 Siri 短语「解锁电视」。

## 配方二：查看剩余时间

只读，不会改变电视状态。

1. 新建快捷指令，添加 **获取 URL 的内容**；
2. URL 填 `http://192.168.1.20:8099/api/state`，方法保持 `GET`；
3. 在 **头部** 添加 `Authorization`：`Bearer sotv_xxxxxxxxxxxxxxxx`；
4. 添加 **从输入获取字典**（Get Dictionary from Input），输入选上一步的结果；
5. 添加 **获取字典值**，键填 `learning.remainingSeconds`，类型选数字；如果当前系统版本不支持在键里写点号路径，就先取 `learning` 字典，再对它取 `remainingSeconds`；
6. 添加 **计算**，把上一步的值除以 `60`，再四舍五入；
7. 添加 **显示结果**，内容可以写成「还能看 [计算结果] 分钟」；
8. 运行测试。

小提示：

- `remainingSeconds` 为 `-1` 表示当前是不限时或持续锁定状态，可以在「获取字典值」后加一个 **如果** 判断，分别显示「不限时」和「已锁定」；
- 想看锁定原因，再用一次「获取字典值」读取 `learning.reason`，常见值：`quota`（今日配额用完）、`rounds`（答题组数用完）、`schedule`（不在可用时段）、`timeup`（可看时长用完）、`locked`（家长锁定）、`rest`（强制休息）。

## 配方三：立即锁定

和配方一相同，只是请求体改成：

```json
{"action": "lock", "minutes": 0}
```

`minutes` 为 `0` 表示一直暂停，直到在家长面板点取消，或在快捷指令里再调用一次 `cancel`。建议单独做一个「恢复管控」快捷指令：

```json
{"action": "cancel"}
```

## 参数表

`POST /api/remote` 的请求体字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `action` | 字符串 | `unlock` 临时解锁、`lock` 立即锁定、`cancel` 取消当前解锁/暂停 |
| `minutes` | 数字 | `unlock` 必填，1–1440 分钟；`lock` 填 `0` 表示一直暂停，也可以填 1–10080 分钟定时解除；`cancel` 不需要 |

其他可用动作（本页未做成配方，需要时把 `action` 换掉即可）：

| `action` | `minutes` | 说明 |
|---|---|---|
| `indefinite` | 不需要 | 持续关闭管控，直到 `cancel` |
| `credit` | -480–480 的非零整数 | 增加或扣减今天的奖励余额，跨天清零 |

## 在家与在外

- **在家**：直接访问 `http://<电视IP>:8099`，需要手机和电视在同一局域网。HTTP 是明文，只适合可信家庭网络。
- **在外**：快捷指令无法直接访问家里的局域网地址，需要自己搭一条私有通道，例如 WireGuard、Tailscale 或 Cloudflare Tunnel。把 URL 换成隧道提供的地址即可，例如：

  ```text
  https://studyontv.example.com/api/remote
  ```

  使用 Tailscale 时也可以直接用设备的 MagicDNS 名称。不要把 `8099` 端口直接映射到公网，也不要在路由器上做端口转发。

## 常见问题

| 现象 | 处理 |
|---|---|
| 返回 `401` | 令牌错误或已吊销，回家长面板重新生成，并同步更新快捷指令头部 |
| 返回 `403` | 令牌没有对应权限：解锁/锁定需要 **控制**，读取状态需要 **只读** |
| 返回 `429` | 设备端限流 240 次/分钟，等一分钟再试 |
| 一直超时 | 确认电视 App 在运行、IP 没变；在外使用时确认隧道在线 |
| 返回 `400` | 检查请求体是不是合法 JSON，`minutes` 用数字而不是文本 |

## 安全提醒

- 快捷指令会随 iCloud 同步，令牌可能出现在其它登录同一 Apple ID 的设备上；不要把带令牌的快捷指令分享给别人；
- 只使用「控制」或「只读」权限的集成令牌，泄露后在家长面板点「吊销」即可，不需要改管理密码；
- 建议把快捷指令命名为不含令牌、也不含家庭地址的名称，避免截图泄露。
