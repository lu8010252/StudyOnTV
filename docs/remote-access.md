# 远程管理电视（出门也能打开家长面板）

家长面板默认只在家里同一个网络下能用：浏览器打开 `http://电视IP:8099/`（见 [安装指南](./install.md#家长面板地址)）。人在公司、出差在外时，这个地址是打不开的——家里路由器做了地址转换，外网没有办法主动连到电视。

这篇文档给三种把面板"接出去"的办法，从省心到麻烦依次是 Tailscale、Lucky、frp。三者都只是让网络能通，面板本身的家长密码验证照常生效。

## 先确认这几件事

1. **面板地址先记下来**。电视重启后地址可能变化，按 [安装指南](./install.md#家长面板地址) 在路由器里给电视固定 DHCP 租约，后面的配置都要填这个 IP。
2. **家长密码要有强度**。面板不限制来源地址，任何能连到 8099 的设备都能打开登录页，密码是这条链路上唯一的防线。至少 12 位、不要用生日和连号；连续输错 5 次会锁 1 分钟，这只能减慢暴力尝试的速度。
3. **面板是明文 HTTP**。除了 Tailscale（链路本身加密），另外两种方案在公网上传输时，密码和登录令牌都是明文，必须再套一层 HTTPS。
4. **不要直接做端口转发**。在路由器上把 8099 映射到公网是最简单也最危险的做法：扫描器几分钟内就会找到你家 IP 并开始撞密码。下面的方案至少带了隔离或加密。
5. **只给自己用**。这些客户端只装在家长自己的手机 / 电脑上，不要装到孩子能碰到的设备。

## 方案一：Tailscale（推荐）

Tailscale 用 WireGuard 把你自己的几台设备组成一个虚拟局域网，设备之间直接加密通信，不需要公网 IP，也不需要在路由器上开任何端口。对外的互联网上不会出现你的电视。

免费个人套餐就够一个家庭用。

### 配置

1. 打开 <https://login.tailscale.com/> 注册账号（邮箱、Google、微软账号都行）。
2. 手机和电脑装 Tailscale 客户端，用同一个账号登录。
3. 电视上装 Tailscale：
   - 先在电视应用商店搜一下，部分 Android TV 商店里有；
   - 搜不到就把官网下载的 Android 版 APK 拷到 U 盘，插到电视上用文件管理器或电视管家安装（选 arm64 版本，装之前核对包名 `com.tailscale.ipn`）；
   - 打开后点 Connect，它会显示一个网址和一串字符，用手机浏览器打开那个网址、输入字符即可完成登录（电视上不用输账号密码）。
4. 回到后台的 Machines / Devices 页面，找到电视那一行，记下它的 `100.x.y.z` 地址。建议把这个设备的 Key expiry 设为 Disable——默认会在几个月后要求重新登录，而电视上做这件事很麻烦。
5. 手机上保持 Tailscale 开着，浏览器访问 `http://100.x.y.z:8099/`，就是家长面板。开启 MagicDNS 后也可以直接用 `http://电视设备名:8099/`。
6. 只想让手机访问电视时，可以在后台的 Access controls 里加一条限制（手机能访问电视的 8099，别的设备之间不互通）。规则语法见 Tailscale 官方 ACL 文档。

### 注意事项

- 电视待机或关机时客户端会掉线，这时打不开是正常的；开机后要等十几秒到一分钟。
- 电视的系统清理后台时可能把 Tailscale 一起杀掉。和本应用一样，需要在电视的「自启动 / 省电策略」里放行 Tailscale。
- `100.x` 地址由 Tailscale 分配，不随家里路由器换 IP 而变化，比记局域网地址更省心。
- 这是三种方案里唯一"公网上不留入口"的做法，链路加密也解决了明文 HTTP 的问题。

## 方案二：Lucky（家里有公网 IP 或 IPv6）

Lucky 是开源的网关工具（反向代理、DDNS、自动证书、内网穿透），一般装在 NAS 或常开的 Docker 主机上。适合家里有公网 IPv4 / IPv6、又想要域名和自动续期的 HTTPS 证书的情况。

家宽的公网 IPv4 越来越少，IPv6 比较常见。注意：很多公司网络没有 IPv6，出门用手机流量一般可以。

### 配置

1. 装 Lucky（把 `/你的目录` 换成实际路径）：

   ```bash
   docker run -d --name lucky --restart=always --net=host \
     -v /你的目录/lucky:/goodluck gdy666/lucky
   ```

   启动后浏览器打开 `http://这台机器的IP:16601`（端口以启动日志为准），先设置后台管理账号和强密码，并尽量只在内网访问后台。

2. 在「Web 服务」里新建一条反向代理规则：监听你自己的域名，后端填 `http://电视IP:8099`。
3. 在「DDNS」里把域名解析到家里的公网 IP。IPv6 场景下要确认路由器已放行这台机器的入站。
4. 在「证书」里用 ACME 申请 Let's Encrypt 证书（域名要先能解析到这台机器），然后把第 2 步的规则切成 HTTPS。
5. 用 `https://tv.你的域名/` 打开面板。

Lucky 还有「STUN 内网穿透」，没有公网 IP 也能靠打洞映射出一个外网端口。但它依赖运营商的 NAT 类型，打洞失败就连不上，稳定性不如 Tailscale；想省心建议直接选方案一。

## 方案三：frp（有公网服务器）

frp 需要一个有公网 IP 的 VPS（1 核 1G 足够）。它把你的内网端口直接暴露到 VPS 上，**安全性完全依赖家长密码**，所以必须配合 HTTPS。

一个现实前提：**电视上一般跑不了 frpc**。frp 官方没有 Android 客户端，除非电视能 root 或能装 Termux。所以正确做法是在家里一台常开的机器上跑 frpc（NAS、树莓派、OpenWrt 路由器、旧电脑都行），由它转发电视的 8099。

### 配置

1. VPS 上装 frps（v0.52 及以上用 TOML 配置，旧版本是 INI），写 `frps.toml`：

   ```toml
   bindPort = 7000

   auth.method = "token"
   auth.token = "换成一串很长的随机密码"

   # 客户端必须用 TLS 连接
   transport.tls.force = true
   ```

   启动：

   ```bash
   ./frps -c frps.toml
   ```

   VPS 防火墙 / 安全组放行 7000 和下面要用的映射端口（例子里是 18099）。

2. 家里常开机器上装 frpc，写 `frpc.toml`：

   ```toml
   serverAddr = "你的VPS公网IP"
   serverPort = 7000

   auth.method = "token"
   auth.token = "和 frps 里一致"

   [[proxies]]
   name = "sotv-panel"
   type = "tcp"
   localIP = "192.168.1.30"   # 电视的固定 IP
   localPort = 8099
   remotePort = 18099          # VPS 上对外开放的端口
   ```

3. 启动 frpc，在任意设备上打开 `http://VPS的公网IP:18099/`，就是家长面板。

### 必做的加固

- **套 HTTPS**。用 Caddy 最省事，两行配置就自动申请并续期证书：

  ```
  tv.example.com {
      reverse_proxy 127.0.0.1:18099
  }
  ```

  然后把 `remotePort` 只监听在本机（frp 里可以配合 VPS 的防火墙只允许 127.0.0.1 访问 18099），对外只开 443。
- **别用常见端口**做 `remotePort`，8099、80、443 这类会被扫得最勤。
- **用完就停**。frpc 平时不用时停掉，需要时再开（`systemctl start/stop frpc`）。面板里用完记得退出登录，当前的登录令牌会立即失效。
- frp 还有 stcp / xtcp（点对点、不暴露公网端口）两种更安全的模式，但要求访问端也跑 frpc，手机上做不到，这里不展开。
- 做好准备：暴露在公网的端口每天都会收到大量登录尝试，这是常态。确认密码足够长、错误锁定生效即可，不要在日志里看到就慌。

## 三种方案怎么选

| 你的情况 | 选哪个 |
|---|---|
| 没有公网 IP、不想折腾、只给自己手机用 | Tailscale |
| 有 VPS，想让任何设备不装客户端也能打开 | frp + HTTPS 反代 |
| 有公网 IPv4 / IPv6 和域名，想要 HTTPS 和自动续期 | Lucky |
| 不想在公网上留下任何入口 | 只有 Tailscale 做得到 |

## 连不上时怎么查

先在家里网络下试 `http://电视IP:8099/`：

- **能打开** → 面板正常，问题在网络方案，看下面几行；
- **打不开** → 先看电视是否开机、IP 是否变了、端口是不是被占用后退到了 8090（面板地址以电视屏幕上显示的为准），以及家长面板「设备」页里的服务状态。

按方案排查：

| 方案 | 常见原因 |
|---|---|
| Tailscale | 电视被清理后台、客户端没连上、Key expiry 到期、电视待机 |
| Lucky | 域名解析没更新、证书续期失败、家宽 80/443 被运营商封（改用 DNS 验证或换端口）、IPv6 入站被路由器拦住 |
| frp | VPS 防火墙没放行、`remotePort` 被占用、frpc 没启动（看 `journalctl -u frpc -f`）、家里那台机器的 IP 变了 |
