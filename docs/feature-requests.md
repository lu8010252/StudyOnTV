# 新增需求使用说明

## 多个孩子分开管控

家长后台「设置 → 孩子」可以添加、改名、切换和删除孩子档案，最多 8 个。每个孩子各自一套：

- 学习规则（时长、时段、组数、奖励、学习内容与公益视频）
- 学习进度、进行中的一轮、错题解析倒计时、复习（艾宾浩斯）进度
- 剩余 / 免费时长、每日用量、完成组数和成长记录

题库、朗读设置、AI / 批改配置、远程题库是全家共用的。新添加的孩子沿用当时的规则，不用重新配一遍，之后可以单独调整。

电视端在「开始答题」那一屏会列出所有孩子，孩子点自己的名字就能开始，不必每次找家长切换；只剩一个档案时保持原来的样子。切换孩子前会把还没记下的观看时长记在原孩子名下，不会算到别人头上。第一个孩子不能删除（可以改名），删除其他孩子会一并清掉他的学习记录、使用时长和复习进度，题目本身保留。

从旧版本升级时，原有数据全部归第一个孩子，升级不需要手动迁移。

## 错题库与错题优先

每道题都会记下最近一次作答的结果，答错过的题就是错题。家长可以在「学习计划 → 答题范围」打开「错题优先」（默认关闭）：

- 答错的题优先再出，答对一次后回到正常顺序。
- 加练题也从错题里选，错题不够时再按正常顺序补，不会让任务卡住。
- 题库页「更多筛选」里的「掌握」可以只看错题，筛选处还会显示错题数量；打开题目详情能看到最近一次是答对还是答错。

错题记录按题目保存，跨重启不丢；答对一次就退出错题库。

## 隐藏桌面图标

家长面板「设置 → 设备」可以打开「隐藏桌面图标」，默认关闭。打开后桌面和电视应用列表里不再显示「题了个题」，孩子看不到入口，也不容易误点或随手卸载。

它只是关掉桌面入口，应用本身、后台管控服务、无障碍和开机启动都不受影响；和厂商自带的「隐藏应用」不同，不会把应用在系统里藏起来、连带影响后台运行。

恢复方法：

- 点通知栏里「使用时间管理」的常驻通知，直接打开应用；
- 或在家长面板「设置 → 设备」里关闭「隐藏桌面图标」。

隐藏图标不能阻止在系统设置里卸载，要防卸载请配合「防卸载」一起用。如果应用被系统强制停止、通知也消失了，需要在系统设置里卸载重装才能恢复图标。

## 时长、学习模式与多孩子

家长管理页「学习计划 → 任务与解锁」新增：

- **调整剩余时间**在首页打开，可加时或提前收走 1–480 分钟。仅改变今天的奖励/免费余额和今日总额度，不改规则中的每日上限；跨天恢复原规则。提前收走会依次扣奖励、每日免费、开机免费余额，最低为零。时段、强制休息和家长锁定仍有效。
- **每次开机 / 唤醒免费时长**：0 为关闭；重开应用或服务不会重复发放，实际开机或关屏后唤醒时重新分配。这部分也受每日额度与时段约束。
- **每日时长上限 / 每日组数上限**可独立关闭。默认保留原限制。
- **答对指定题数（错题重练）**：累计答对目标数量后解锁，不要求连续答对，不计算通过比例；答错的当前题重新练习。该模式不叠加原有加练池。
- **答错后查看解析**：0 为关闭，可以设置 60 秒；设备端保存期限，刷新或重开应用不能提前跳过。倒计时期间既不能进入下一题，也不能使用奖励时间。
- **学习页字号**：75–200%，即时影响被控设备的题干、选项与解析。

「答题范围」可按题库、科目、年级多选，开启「孩子选择年级」后，每轮从家长允许且实际有启用题目的年级中选择；按题库、科目和年级范围筛选后，只有一个可选年级时自动使用该年级，直接开始答题，多个年级时才显示选择。进行中的一轮不能通过切换年级重新开始。

「时间计划」新增独立的强制休息：累计实际观看 N 分钟后休息 M 分钟。关屏、答题不计观看，休息中不消耗余额；已有余额不能跳过休息。状态跨应用重启保存，同次开机按单调时钟判断期限，设备重启后使用保存的结束时间。休息结束不补每日额度、不重置完成组数。家长临时解锁仍可主动放行。

## 公益视频

「学习内容」支持答题、公益视频、视频与答题交替。家长填写可直接播放的 HTTP/HTTPS 视频地址（例如有权使用的 MP4），设置每次实际观看 1–30 分钟。

学习页会打开内置播放器，实际播放时累计；暂停不累计，拖动进度不能直接领取奖励，短视频可循环直到完成时长。完成后领取原规则设置的每组奖励，受当日额度和组数限制。视频模式用固定的每组奖励，不按题目星级计算。

家长修改「每次视频学习分钟」后立即生效：同一天、同一地址的进行中任务会被沿用，已看过的进度保留并按时长截断，不需要等任务结束。跨天或家长换掉地址后旧任务作废，播放页会自己退出回到学习页重新开始，不会停在一个不会再涨的任务上。

播放失败（地址不是媒体文件、编码不被这台电视支持、网络不通）不会再无限重播或一直停在「还需观看 N 秒」上：播放器报错、有声音一直没有画面、或者长时间连加载都没完成时，学习页会显示具体原因并停下，家长据此换成 H.264 编码的 MP4，或把「学习内容」切回答题模式。

网页地址、B 站分享页或需要登录的播放器页面不等于媒体直链，不保证可由 Android VideoView 播放。项目没有内置或抓取第三方视频内容。

## 多题库、统计与远程同步

题目新增「题库名称」字段。可以按题库筛选、选择全部筛选结果、删除整个题库（包括暂停题）、按题库限制出题范围。导入可以指定默认题库名称；JSON 内已有题库名称会保留。

题目详情显示出题次数、作答次数、正确次数对应的正确率。统计从本版本开始记录；旧版本只有回答事件，没有可靠的展示事件，因此不会伪造历史出题次数。

「题库 → 远程题库与自动补题」支持最多 20 个远程来源。每个来源配置名称、JSON 地址、启用状态；设备每 15 分钟拉取，也可立即同步。多个设备使用同一地址即可共享源题库：

```json
{"items":[{"id":"math-1","bank":"数学","type":"single","q":"2 + 3 = ?","a":["4","5"],"k":1,"level":"一年级"}]}
```

同步后的题库显示为「远程·来源名称」。远程 ID 加来源标记，避免覆盖本地题目；相同来源的稳定 ID 保留统计。整批下载、解析、校验均成功后才提交变更，失败回滚并保留本地题库。只删除该来源中已移除的题目。移除来源停止同步，已下载题目可以手动按题库删除。

自动 AI 补题默认关闭。开启后需填写出题范围、补题题型（单选 / 多选 / 判断 / 填空 / 主观题，可多选，至少一种；电视上用遥控器填字麻烦时可以只补选择题）、最低启用题数、每批题量和掌握标准。没设置过题型的老配置仍按「单选 + 填空」补题。达到最少作答次数及正确率的题目暂停保留；启用题量低于阈值时，调用已配置的 AI 生成新题，存入「AI补题」。这会使用家长所配服务的网络及额度，失败信息显示在同步状态中，不删除原有题目。

## Word / PDF 导入

导入支持 JSON、DOCX、文字版 PDF、TXT。文档在家长浏览器本地提取文字；识别出的题目先转为可检查的 JSON 预览，再确认入库。DOCX/PDF 解析器按需加载，不阻塞平时打开 AI 设置或题库页面。

可识别的文档格式示例：

```text
1. 2 + 3 = ?
A. 4
B. 5
答案：B
解析：2 加 3 等于 5。

2. 选出偶数
A. 2 B. 3 C. 4
答案：AC

3. 苹果的英文是什么？
答案：apple|Apple
```

题目需有明确答案。扫描 PDF 的 OCR、旧二进制 `.doc`、复杂排版/公式图片自动转题不在当前解析器能力内；此时会提示修正文档，不会猜测答案入库。每个文档最大 20 MB、PDF 最多 150 页，单次提交仍受设备 API 4 MB 上限约束。

## 图片、音频、朗读和语音作答

题目可填写图片地址、音频地址与语言（中文、粤语、台湾国语、美式英语、英式英语，或「跟随设备系统语言」）。题目图片直接显示；音频在 Android 端使用原生播放通路，以免被后台视频静音逻辑一起静音。JSON 中也可以使用不超过 500 KB 的 `data:image/…` 图片。

「奖励与复习 → 题目朗读」的「朗读语言」可以选跟随每道题的标注、跟随设备系统语言，或者固定为普通话 / 粤语 / 台湾国语 / 英式英语 / 美式英语。系统是粤语（或繁体中文）的设备选「跟随设备系统语言」即可，题目不必逐条改语言标注。题目没有标注语言时同样按系统语言朗读和识别；没选中对应语言时回落设备默认语言并提示。

「奖励与复习 → 题目朗读」提供系统、Azure、阿里云、自动选择。可以自动朗读每道题，或手动点击朗读。自动模式优先已配置的 Azure，其次阿里云，再回落系统语音；云端失败静默回落系统语音。系统朗读需要设备已安装相应语言语音引擎。

Azure 配置 Key、区域、可选音色；阿里云配置 AppKey、AccessKey ID、AccessKey Secret、可选音色，设备自动签名换取并缓存 Token。密钥仅存设备，接口只返回是否已设置，空白保留旧值，可显式清除。全屏页和悬浮学习页共用朗读实现及辅助语音音频属性。

电视填空/主观题提供「语音输入 / 重录」，可编辑转写、重录，再确认回填答案。识别语言使用该题语言设置。无识别服务时保留文字输入；系统/遥控器拦截语音键的厂商行为仍需对应真机验证。当前按转写文本判分，没有实现发音评分。

## 后台与防卸载

流量辅助播放识别默认关闭；只在桌面/系统临时窗口等前台不明确时，结合整机流量与媒体音频状态辅助判断，下载流量不能单独触发计时。

可关闭后台锚点窗口或倒计时角标，但两者独立。关闭锚点后应验证本机计时、到点拦截、待机恢复。`tv-vigil` 源码分析及本项目外部 ADB 看门狗用法见 [后台恢复](./background-recovery.md)。

很多电视、投影和平板把原生设置菜单精简或藏了起来，导致找不到应用管理和授权入口。权限引导页底部新增「打开系统设置」，直接调起完整系统设置（打不开时回退到本应用的系统详情页）；家长后台「设置 → 后台保活」里也有「打开系统设置」，手机上点一下即可让被控设备跳转。授权完成后返回应用会自动刷新权限状态。

普通设备管理员不等于 Device Owner。设备已有 Device Owner 授权时，使用系统 `setUninstallBlocked` 保护本应用，在开机和服务启动时恢复策略，并允许家长开关。系统持久化策略不依赖 App 先启动，因此能覆盖普通运行期拦截的重启空窗。普通设备管理员模式仍取决于厂商是否遵守；本轮没有把真实设备改为 Device Owner、恢复出厂或清除账号。

平台范围、iPad 与旧 Android 的练习版限制见 [平台支持](./platform-support.md)。
