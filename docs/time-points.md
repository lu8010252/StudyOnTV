# 网课时段与大人豁免

「网课时段」和「大人豁免」用来按**具体的星期几和分钟**安排时间，比 30 分钟一格的「可用时段」更精细。配置入口：家长面板 → **规则** → **时间计划** → **网课时段与大人豁免**。

- **网课时段**：孩子上课的时间段。可以是「自由使用，不扣时长」，也可以是「计入每日限额，并使用这个时段自己的上限」。
- **大人豁免**：到点自动放开给大人看电视 / 看电影，不用临时改规则。豁免期间不扣孩子的时长。

## 优先级

同一时刻有多条规则命中时，按下面的顺序生效（从高到低）：

1. 家长远程「暂停 / 临时解锁」
2. 大人豁免时段
3. 网课时段（自由使用不扣时长）
4. 网课时段（计入限额）
5. 「时段」里配置的 `weekSlots` 可用时段和每日限额

因此，「正在被家长远程暂停」时即使落在大人豁免里仍然锁定；豁免和自由网课重叠时，豁免优先。**同一种规则里有多条同时命中时，按列表顺序取第一条**。

## 网课时段

每条可以设置：

| 项目 | 说明 |
|---|---|
| 名称 | 1–20 个字，会显示在孩子端右上角 |
| 星期 | 可多选，按**真实星期几**（0=周一 … 6=周日） |
| 开始 / 结束 | 精确到分钟，例如 `19:00`–`20:15` |
| 用途 | `自由使用（不扣时长）` 或 `计入每日限额` |
| 时段每日上限 | 仅「计入限额」时需要，1–480 分钟 |

### 自由使用

- 时段内 `status().free = true`，没有锁定原因，**不扣已用时长，也不扣每日免费时长 / 开机免费时长**。
- 时段结束后立刻回到正常计时。
- 不受「时间规则 = 时段内答题解锁，时段外锁定」的限制（自由网课本身就是一个放行窗口）。

### 计入每日限额

- 时段内照常计时、答题和强制休息，只是**每日上限临时换成该时段的分钟数**。
- 只换上限，**不清零已用时长**。例如每日上限 40 分钟、已用 10 分钟，进入上限 60 分钟的网课后还剩 50 分钟。
- 离开时段后恢复原来的每日上限。如果此时已用时长超过原上限，会按 `quota`（今日额度已用完）锁定到第二天。
- 如果家长关闭了「每日限额」，计入限额的分钟数也不会生效（整体不限额）。
- 仍然遵守「时段」里配置的可用时段、强制休息和错题解析停留。

## 大人豁免

- 只配置名称、星期、开始 / 结束，没有「用途」。
- 命中时 `status().free = true`，不扣时长；孩子端显示「大人豁免 · 名称」。
- 优先级高于网课时段，但低于家长远程暂停 / 解锁。
- 适合「周五、周六 21:30–23:00 大人看电影」这类固定安排。

## 跨午夜与边界

- 区间**左闭右开**：`19:00–20:15` 包含 `19:00` 和 `20:14`，不包含 `20:15`。
- **结束早于开始表示跨午夜**：`23:30–00:30` 的 `00:10` 算作**前一天**的安排。例如只勾选周三时，周三 23:30–24:00 和周四 00:00–00:30 都在窗口内；周四 23:45 不在。
- 开始与结束相同（`19:00–19:00`）视为空窗口，保存时会被拒绝。
- 时间按设备本地时钟计算，精确到分钟。

## 节假日

网课时段和大人豁免始终按**真实星期几**生效，不受「时段」里的「节假日按周日时间」影响；「周三 19:00 的网课」在节假日也仍然是周三。

## 旧配置兼容

- 旧配置没有 `timePoints` / `exemptWindows` 时自动补为空数组，行为与升级前完全一致。
- 其它设置页面保存配置时（请求里不带这两个字段），已有时间点会保留，不会被清掉。
- 显式传空数组才会清空。
- 已保存配置里的坏条目会被跳过；格式不对的「计入限额」条目**绝不会被当成自由时段**（避免意外完全放开）。
- 保存时会严格校验：超出范围、开始等于结束、没有选星期、计入限额缺少分钟数等都会拒绝，且**校验失败不会改动已保存的配置**。

## 限制

- 网课时段、大人豁免各最多 50 条。
- 不做重叠检测；重叠时按上面的优先级和列表顺序取第一条。
- 名称最多 20 个字；计入限额的分钟数范围 1–480。
- 自由网课和大人豁免会绕过每日额度，但家长远程暂停仍然优先。
- 计入限额只替换每日上限，不能把两个时段的分钟数相加。

## 孩子端显示

孩子端右上角会读取 `activePoint`：

- 自由网课：`网课时间 · 数学网课 至 20:15`
- 大人豁免：`大人豁免 · 大人看电影 至 23:00`
- 计入限额：`网课时间 · 英语网课 至 18:40 · 还剩 N 组`
