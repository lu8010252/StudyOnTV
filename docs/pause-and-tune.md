# 抽题偏好

## 大人要看电视时

用上游自带的「遥控」：家长后台里可以临时解锁 N 分钟、无限时解锁或立即锁定（本项目原来的「暂停管控」已并入这个功能）。

## 抽题不再重复

- 没做过的题优先；都做过了就先出最久没做的（开启「间隔重复」时仍按到期顺序）。
- 同一轮里出过的题不会再出。
- 「🎛 管控」里可设置**最低星级**（默认 2 星起），先从这个星级以上的题里抽；这个星级的题不够时会自动放宽，不会没题做。

## 答对多次自动停用

用上游的「题库自动化 · 掌握后暂停」（家长后台 → 题库），本项目原来的自动淘汰已删除；升级时之前被淘汰的题会放回题库。

## 接口（需管理令牌）

`GET /api/tune`、`PUT /api/tune/settings`、`GET /api/pause`、`PUT /api/pause`（参数 `{"minutes":60}` / `{"today":true}` / `{"forever":true}` / `{"off":true}`）
