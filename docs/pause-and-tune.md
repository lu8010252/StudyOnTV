# 抽题偏好与自动淘汰

## 大人要看电视时

用上游自带的「遥控」：家长后台里可以临时解锁 N 分钟、无限时解锁或立即锁定（本项目原来的「暂停管控」已并入这个功能）。

## 抽题不再重复

- 没做过的题优先；都做过了就先出最久没做的（开启「间隔重复」时仍按到期顺序）。
- 同一轮里出过的题不会再出。
- 「🎛 管控」里可设置**最低星级**（默认 2 星起），先从这个星级以上的题里抽；这个星级的题不够时会自动放宽，不会没题做。

## 答对多次自动淘汰

同一道题**连续答对**达到设定次数（默认 3 次，可改 2–20，答错会重新计数）后，自动从题库撤下，不再出现。

- 只是撤下，记录还在：AI 出题去重仍会参考它，不会又把同样的题生成回来。
- 每个科目至少保留 10 道题；题库被做空时，已淘汰的题会自动放回来。
- 「🎛 管控」里能看到已淘汰数量，并一键「把已淘汰的题放回题库」（当作新题重做）。

## 接口（需管理令牌）

`GET /api/tune`、`PUT /api/tune/settings`、`POST /api/tune/restore`、`GET /api/pause`、`PUT /api/pause`（参数 `{"minutes":60}` / `{"today":true}` / `{"forever":true}` / `{"off":true}`）
