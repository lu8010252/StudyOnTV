# 积分同步到星星屋

答题得到的积分会推送到「星星屋」（star-house），两边都能看到同一个总分：

- **电视/平板页面**：右上角显示 `⭐ 总积分`，答对一题弹出 `+N ⭐`，通过一组后显示今天已得分数。
- **家长后台**：右下角「⭐ 积分」按钮，可设置、查看余额、手动同步、看最近得分。
- **星星屋后台/前台**：积分记录里出现 📺 标记的「电视答题」条目，和家长手动加分、兑换商品用同一个总分。

## 设置（家长后台 → ⭐ 积分）

1. 填星星屋地址（如 `https://star.8010252.xyz`）和家庭密码，点「获取孩子列表」，选要绑定的孩子。密码只用来换取令牌，不会保存。
2. 勾选「开启积分同步」，保存。

| 项 | 默认 | 说明 |
|---|---|---|
| 计分方式 | 每题固定加分 | 「每题固定加分」：答对一题就加固定分数，不看星级；「按星级加分」：答对一题得 `题目星级 × 每星积分` |
| 每答对一题加几分 | 1 | 「每题固定加分」时用（v0.6.0 起默认方式） |
| 每颗星对应积分 | 1 | 「按星级加分」时用 |
| 通过一组奖励 | 5 | 一组任务通过后额外加分 |
| 每天上限 | 30 | 答题积分的每日封顶，0 表示不限 |

只有计入本组的答对题才得分，加练池里的题不加分；练习模式照常计分。

## 同步机制

- 积分先记入本机账本，再推送星星屋；断网时积攒，每 2 分钟自动补传。
- 每条积分带唯一编号，星星屋按编号去重，重试不会重复加分。
- 总分以星星屋为准：在星星屋里加扣分、兑换商品后，这里下次同步就会更新。
- 在星星屋撤销一条电视答题记录会回退总分，本机不会重发。

## 接口（需管理令牌）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/points` | 设置、余额、待同步数、最近得分 |
| PUT | `/api/points/settings` | 保存设置 |
| POST | `/api/points/children` | 用家庭密码取回星星屋孩子列表 |
| POST | `/api/points/sync` | 立即同步 |

星星屋侧新增：`POST /api/ext/score`（带 `extId` 幂等加分）、`GET /api/ext/children`。需要星星屋更新到包含这两个接口的版本。
