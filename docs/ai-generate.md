# AI 出题（v0.4.0）

题库里的题做多了孩子会背答案，所以加了「AI 出题」：某科**没做过的题**少于阈值时，后台自动调用 OpenAI 兼容接口（包括中转站）出一批新题入库。

入口：家长后台右下角「🤖 AI出题」。

## 设置

| 项 | 说明 |
|---|---|
| API 地址 / Key / 模型 | 完整的 `chat/completions` 地址；留空则沿用「AI 批改」里已配好的那一套 |
| 科目与教材 | 科目、年级、教材版本，加上本学期知识点（每行一个）。默认带了数学（苏教版四上）和英语（人教 PEP 三起），换学期或换版本直接改这里 |
| 每批题数 | 5–30，默认 15 |
| 补题阈值 | 某科没做过的题少于此数就补，默认 80 |
| 每天最多批次 | 默认 6，防止出错时无限调用花钱 |

「保存并立即出一批」会为每门科目各出一批；开启自动出题后，开机 1 分钟起每 10 分钟检查一次。

## 质量保证

1. 出题时带上已有题目让 AI 避开重复，入库前再按题干去重。
2. **独立复核**：把题目去掉答案，让 AI 重新做一遍，答案不一致的题直接丢弃（后台会显示丢弃了几道）。
3. 选项顺序在本地打乱，避免答案总在 A。
4. 格式不合法的题（选项重复、答案序号越界等）直接丢弃。

复核能挡掉大部分算错的题，但不能保证百分之百，家长偶尔抽查一下。AI 出的题 ID 以 `ai-` 开头，「删除全部 AI 题」只删它们，不影响你导入的题。

出题是提前生成并存在本机的，答题时不依赖网络。

## 接口（需管理令牌）

`GET /api/aigen`、`PUT /api/aigen/settings`、`POST /api/aigen/run`、`DELETE /api/aigen/questions`
